If something isn't right, you can send it back.

## Return window

You can return an item within 30 days of its delivery.

## Condition of returned items

Items must be unused and with the tags still attached. We can't accept items that have been worn outdoors, washed or altered.

## Return shipping

You pay for return shipping, unless the item is defective. For a defective item, we cover the return shipping.

## How to start a return

Contact our support team with your order number. A member of the team emails you the return instructions.
